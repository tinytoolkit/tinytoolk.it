Similar to [Jarkman's 26-in-1](@/tools/26-in-1/index.md) selection, this is a Wiha bit holding screwdriver which takes their double-ended bits. It's just a tiny, stubby version.

{{ figure(width=640, path="tools/wiha-stubby/thing.jpg") }}

It has room for 6 double bits in the handle, plus one left in the bit holder itself - so 14 types of bit. It's a little less comfy to use for any amount of time since the handle is not long enough to be gripped by your fingers and palm - but I think the space saving makes it worth it! I've also illegally used random other single ended 1/4" bits in this handle - they disappear a bit into it as they're much shorter, but it can be done in a pinch.

Be careful when seeking this out - there are many other Wiha products that look very similar but are only for single bits. You're looking for part number 43613 (though the driver itself has "3802" printed on it). There may also be other variants which contain the same driver but a different selection of bits.

## Bit holder
I found a [bit holder](https://www.printables.com/model/1604745-14-hex-bit-holder-for-wiha-double-ended-bits) on printables.com and inelegantly trimmed it to a smaller number of slots in the slicer before printing. It's snug in PLA (possibly too snug!).

## Bits
I've replaced some of the default bit selection with "security" variants from the [Wiha Security Bit Reload set 77783](https://www.wihatools.com/products/13-bit-pack-double-ended-security-bit-reload-for-ultra-driver-26inone) meaning I can use it with both regular and security variants of Torx and hex fasteners "for free".

I wish you could pick-n-nix bits - in order to collect all of the double ended bits to make up a complete set you'd need to buy multiple bit reload kits. If anyone from Wiha is reading - hit us up if you could do us a deal on a complete kit!
